🧠 Memory Card Game

A fun and interactive Memory Card Matching Game built to challenge your short-term memory and focus! Players flip cards, try to find matching pairs, and compete for the best score and fastest completion time.

🚀 Features

🎮 Interactive Gameplay – Flip cards, find matches, and track your progress.

⏱️ Timer & Move Counter – Compete against yourself or friends.

📱 Responsive Design – Works smoothly on desktop and mobile.

🔊 Optional Sound Effects – Enhance gameplay with flips, matches, and win sounds.

🎨 Customizable Themes – Change card styles, colors, and difficulty levels (optional).

💾 Local Storage Support – Saves best score/time automatically (optional).
